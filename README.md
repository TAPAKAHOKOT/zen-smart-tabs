# Zen Smart Tabs

Sine JS mod для Zen Browser: по кнопке анализирует открытые вкладки **текущего пространства**, предлагает осмысленные группы и после подтверждения создаёт нативные Zen Folder.

## Что уже работает в MVP

- кнопка со sparkles-иконкой в верхней части сайдбара Zen;
- анализ только текущего Workspace / Space;
- исключение Essentials, служебных страниц и вкладок, уже находящихся в папках или группах;
- отправка в OpenAI только `title + hostname`, без полного URL и содержимого страницы;
- GPT-5 nano по умолчанию и GPT-5 mini как более точный вариант;
- русские, английские или автоматические названия папок;
- предпросмотр перед применением;
- редактирование названий и исключение отдельных вкладок или целых групп;
- создание нативных Zen Folder;
- отмена последней группировки;
- API key не записывается в prefs, `localStorage`, SessionStore или файлы.

## Важное ограничение Zen

Текущая реализация `gZenFolders.createFolder()` внутри Zen автоматически закрепляет каждую вкладку. Это поведение самого браузера, а не мода. Мод предупреждает об этом до применения. Его Undo распаковывает созданные папки и снимает закрепление с вкладок, которые до группировки не были закреплены.

## Что потребуется

1. Актуальный Zen Browser.
2. Sine 2.3.x или новее.
3. OpenAI API key с включённым API billing / credits.
4. Публичный GitHub-репозиторий, из которого Sine сможет установить этот мод.

Важно: подписка ChatGPT Plus/Pro сама по себе не является балансом OpenAI API. API оплачивается отдельно на OpenAI Platform.

Официальный репозиторий и установщики:

- https://github.com/CosmoCreeper/Sine/releases/latest

После установки перезапусти Zen.

## Подготовка мода на GitHub

1. Создай новый репозиторий, например `zen-smart-tabs`.
2. Положи **в корень репозитория** эти файлы:
   - `theme.json`
   - `main.uc.js`
   - `chrome.css`
   - `README.md`
3. Не вставляй API key ни в один файл и не коммить его в GitHub.
4. В `theme.json` можно заменить `"author": "Local user"` на своё имя или ник.

## Установка мода через Sine

1. Открой настройки Zen → раздел Sine Mods.
2. Открой настройки самого Sine и включи **Allow unsafe JS / External JS** (`sine.allow-unsafe-js`).
3. В поле установки собственного мода вставь:

   ```text
   your-github-name/zen-smart-tabs
   ```

   Подойдёт и полный URL GitHub-репозитория.
4. Нажми Install.
5. Перезапусти Zen, если Sine попросит это сделать или кнопка не появилась сразу.

Кнопка со значком ✨ должна появиться в верхнем блоке сайдбара.

## Как пользоваться

1. Открой несколько связанных вкладок в одном Space.
2. Нажми кнопку Smart Tabs.
3. Вставь OpenAI API key. Он останется только в оперативной памяти этого окна Zen.
4. Выбери модель и максимальное число папок.
5. Нажми «Проанализировать вкладки».
6. Проверь названия и состав групп.
7. Нажми «Создать папки».

## Более безопасный способ передать ключ

Мод также умеет читать переменную окружения `OPENAI_API_KEY`. Тогда поле можно оставить пустым.

macOS / Linux в терминале:

```bash
export OPENAI_API_KEY="sk-proj-..."
```

После этого Zen нужно запустить из того же окружения. На macOS приложение, открытое обычным кликом из Dock/Finder, часто не наследует переменные shell, поэтому для личного MVP проще вводить ключ при запуске мода.

## Безопасность

Это персональный локальный прототип. OpenAI рекомендует не размещать секретные API keys в браузерном client-side коде и для публичного продукта использовать собственный backend.

В этой версии риск уменьшен так:

- ключ не сохраняется и очищается при выгрузке мода / закрытии окна;
- ключ никогда не логируется;
- запрос содержит только заголовок вкладки и hostname;
- установлен `store: false` для отключения сохранения Response как application state; это не означает Zero Data Retention и не отменяет возможные abuse-monitoring logs;
- полный URL, query string, хэш, favicon и текст страницы не отправляются;
- уже существующие папки не анализируются и не перестраиваются.

Для ключа лучше создать отдельный OpenAI Project, ограничить разрешения и поставить небольшой monthly budget / alert. Не устанавливай непроверенные JS-моды рядом: другой привилегированный мод теоретически может прочитать состояние браузера.

## Отладка

Открой Browser Console и ищи сообщения:

```text
[ZenSmartTabs 0.1.0]
```

Частые причины ошибок:

- `401` — неверный или отозванный API key;
- `403` — ключу недоступна выбранная модель или проект;
- `429` — rate limit либо закончился бюджет/кредиты;
- кнопка отсутствует — не включён `sine.allow-unsafe-js`, мод выключен или требуется перезапуск;
- папки перестали создаваться после обновления Zen — изменился внутренний API `gZenFolders`.

## Ограничения MVP

- код проверен синтаксически, но его всё равно нужно испытать в конкретной установленной версии Zen;
- внутренние API Zen не публичные и могут измениться после обновления;
- Undo делает best-effort восстановление порядка вкладок;
- анализируется максимум 100 подходящих вкладок за запрос;
- не поддерживается приватное окно;
- вкладки в уже существующих группах/папках не трогаются.
